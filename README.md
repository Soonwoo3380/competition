## Project Summary

### 1. 온라인 채널 제품 판매량 예측

제품 코드와 판매량 데이터를 바탕으로 미래 판매량을 예측하는 프로젝트입니다.

초기에는 모델 구조와 파라미터를 조정하며 성능을 높이려 했지만 순위가 정체되었습니다.
이에 모델을 계속 변경하기보다 현재 입력 정보가 실제 판매량 변화를 충분히 설명하고 있는지 다시 살펴봤습니다.

제품 코드만으로는 제품마다 다른 구매 특성이나 소비 주기,
함께 사용되는 제품 간 관계가 충분히 드러나지 않는다고 판단했습니다.
이를 보완하기 위해 제품명, 브랜드, 용량, 제품 유형, 가격 등의 정보를 조사해 데이터를 보완했습니다.

이후 제품을 유사한 특성에 따라 묶고,
함께 구매될 가능성이 높은 제품 관계와 상대적인 소비 주기를 새로운 특성으로 설계했습니다.
요일과 공휴일 등 시간적 정보도 추가해 실제 소비 패턴이 입력 데이터에 더 잘 반영되도록 했습니다.

**Key Points**

- 외부 조사를 통한 제품 정보 보완
- 제품 간 구매 관계 및 소비주기 기반 피처 설계
- 요일 및 공휴일 등 시간 정보 반영
- 시계열 판매량 예측 모델 구축
- 팀 리더로서 실험 방향 및 역할 조율
- 최종 순위: **57위 / 747팀**

### 2. 제품 이상 여부 판별

제조 공정 데이터를 활용하여 제품의 정상 및 이상 여부를 분류하는 프로젝트입니다.

여러 제조 공정에서 생성된 센서 값과 작업 정보가 하나의 데이터셋에 포함되어 있었고,
공정마다 변수의 구조와 특성이 다르다는 점에 주목했습니다.

먼저 결측치와 단일 값 변수를 정리하고,
각 변수가 어느 공정에서 생성된 정보인지 확인했습니다.
이후 Resin 계열과 Autoclave 계열 공정의 데이터 특성이 다르다고 판단해
데이터를 분리하여 각각 모델링했습니다.

이상 제품의 비율이 낮은 문제에는 클래스 불균형을 고려한 학습과 검증을 적용했습니다.
또한 특정 모델 하나에 결과가 좌우되지 않도록
LightGBM, CatBoost, XGBoost의 결과를 결합했습니다.

**Key Points**

- 제조 공정별 데이터 구조 및 변수 특성 분석
- Resin 계열과 Autoclave 계열 데이터 분리 모델링
- 클래스 불균형을 고려한 학습 및 검증
- LightGBM, CatBoost, XGBoost 기반 앙상블
- 제조 데이터의 생성 맥락을 반영한 모델링
- 최종 순위: **31위 / 740팀**

### 3. 뉴스 기사 레이블 복구

레이블이 제거된 약 6만 건의 뉴스 기사를 6개 카테고리로 분류하는 프로젝트입니다.

정답 레이블을 사용할 수 없는 환경에서
SentenceBERT를 활용해 뉴스 문장을 임베딩하고,
KMeans Clustering을 통해 의미적으로 유사한 기사들을 군집화했습니다.

이후 각 클러스터의 주요 키워드와 대표 문장을 분석해 군집의 의미를 해석하고,
클러스터 번호를 실제 뉴스 카테고리에 대응시키는 방식으로 레이블을 복구했습니다.

**Key Points**

- 텍스트 정제 및 문장 전처리
- SentenceBERT 기반 문장 임베딩
- KMeans 기반 뉴스 기사 군집화
- 주요 키워드 및 대표 문장을 통한 클러스터 해석
- 클러스터와 실제 뉴스 카테고리 매핑
- 비지도 학습 기반 레이블 복구 파이프라인 구축
- 최종 순위: **8위 / 129팀**
